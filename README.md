# AZ-104 Study Notes & Quiz

Interactive study site for the Microsoft Azure Administrator (AZ-104) exam.

- **17 lesson guides** covering Azure administration and governance & compliance
- **90 practice questions** with an explanation for every answer choice
- **Review mode** to retry only the questions you missed
- Progress is saved in your browser (localStorage), works offline once loaded
- Mobile friendly, built for studying on a phone

Everything is a single `index.html` with no dependencies or build step.

Based on Alex Potasnick's AZ-104 course. Notes are original paraphrased summaries, not transcripts.
